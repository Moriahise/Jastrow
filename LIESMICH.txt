SO RICHTEST DU ES EIN
----------------------------------------------------------------
1. Entpacke das ZIP-Archiv

2. Kopiere deine Quelltexte in den sources/ Ordner:
   - Behalte die Ordnerstruktur bei (Talmud, Mishnah, etc.)
   - Alle TXT-Dateien werden automatisch gefunden
   - Unterordner werden rekursiv durchsucht

3. Starte mit start_manual.bat


FEATURES
----------------------------------------------------------------
- Rekursive Suche in allen Unterordnern von sources/
- Zeigt Quellenkontext (3 Zeilen um das Wort herum)
- Quellpfad wird angezeigt: "Talmud > Bavli > Berakhot"
- Bis zu 10 Quellen pro Wort
- Woerterbuch-Uebersetzungen (DE/EN)

NEUE TOOLS (im Tooltip-Fenster)
----------------------------------------------------------------
- Text markieren und kopieren (Ctrl+C)
- Rechtsklick-Menue mit Optionen
- "Wort kopieren" - kopiert nur das hebraeische Wort
- "Uebersetzungen kopieren" - kopiert alle Bedeutungen
- "Alles kopieren" - kopiert den kompletten Eintrag
- "Sefaria" - oeffnet Sefaria-Suche im Browser
- "Morfix" - oeffnet Morfix-Woerterbuch im Browser
- "Wortanalyse" - zeigt Buchstaben, Gematria, Wortstamm

SO FUNKTIONIERT ES
----------------------------------------------------------------
1. Starte das Programm
2. Markiere hebraeischen Text in beliebiger Anwendung
3. Druecke Ctrl+C (kopieren)
4. Fenster erscheint mit:
   - Bedeutungen (Deutsch/Englisch)
   - Quellen mit Kontextausschnitt
   - Quellpfad (z.B. "Talmud > Bavli > Gittin")


OPENAI API-INTEGRATION (NEU!)
----------------------------------------------------------------
Das Programm kann Quellentexte mit OpenAI uebersetzen:

1. Klicke auf "API" in der Toolbar oder im System Tray Menue
2. Gib deinen OpenAI API-Key ein
3. Waehle Zielsprache (Deutsch/Englisch)
4. Waehle Modell (GPT-3.5 Turbo oder GPT-4o-mini)

Nutzung:
- Klicke auf "[Uebersetzen]" unter einer Quelle
- Oder markiere Text und Rechtsklick -> "Auswahl uebersetzen"
- Die Uebersetzung erscheint direkt im Fenster

API-Key erhalten: https://platform.openai.com/api-keys
Konfiguration wird in config.json gespeichert.


SEFARIA API-INTEGRATION (NEU!)
----------------------------------------------------------------
Das Programm fragt bei jeder Suche automatisch die Sefaria API ab
und zeigt Eintraege im Sefaria-Style an:

Funktionen:
- Automatische Abfrage der Sefaria Lexikon-API
- Anzeige wie auf sefaria.org (siehe Screenshot)
- Vokalisierte Headwords mit Wortart (m.n., f., etc.)
- Nummerierte Definitionen
- Klein Dictionary UND Jastrow Dictionary Eintraege
- Referenzen und Etymologie
- Lokaler Cache (7 Tage gueltig)

Einstellungen (ueber API-Button):
- Sefaria API aktivieren/deaktivieren
- Automatisches Update des lokalen Woerterbuchs

Neue Ordnerstruktur:
JastrowDictionary/
|-- sefaria_cache/                SEFARIA CACHE (automatisch)
|   |-- sefaria_lexicon_cache.json
|   +-- local_sefaria_entries.json

Buttons im Tooltip:
- "🔄 Aktualisieren" - Holt aktuelle Daten von Sefaria
- "Sefaria öffnen" - Oeffnet Sefaria-Suche im Browser


QUELLEN-ANZEIGE (NEU!)
----------------------------------------------------------------
- Hebraeische Texte werden RTL (rechts-nach-links) formatiert
- Das gesuchte Wort wird GELB HERVORGEHOBEN im Kontext
- Jede Quelle hat einen [Uebersetzen] Button
- Uebersetzungen erscheinen kursiv unter dem Originaltext


TIPPS
----------------------------------------------------------------
- Je mehr TXT-Dateien in sources/, desto mehr Quellen werden gefunden
- Die Dateien sollten UTF-8 kodiert sein
- Hebraeische Windows-Kodierung (CP1255) wird auch unterstuetzt

INDEX-CACHE (NEU!)
----------------------------------------------------------------
- Beim ersten Start werden alle Dateien indexiert (kann dauern)
- Der Index wird in "source_index.cache" gespeichert
- Bei weiteren Starts wird der Cache geladen (sehr schnell!)
- Neu-Indexierung nur wenn:
  * Neue Dateien hinzugefuegt wurden
  * Dateien geloescht wurden
  * Dateien geaendert wurden
- Cache loeschen: Einfach "source_index.cache" loeschen


FEHLERBEHEBUNG
----------------------------------------------------------------
Problem: "Keine Quellen gefunden"
Loesung: Kopiere TXT-Dateien in den sources/ Ordner

Problem: "Langsamer Start"
Loesung: Normal bei vielen Quelldateien (einmalige Indexierung)

Problem: "Kodierungsfehler"
Loesung: Speichere TXT-Dateien als UTF-8
